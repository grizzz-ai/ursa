# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public GitHub Issue.

Send a confidential report to [zzz@grizzz.ai](mailto:zzz@grizzz.ai). Include a clear description,
reproduction steps, the affected version or commit when known, and any suggested mitigation. Do not
include credentials, access tokens, private keys, or personal data.

Reports are triaged as they are received. This project does not publish a numerical response SLA.

## Scope

Reports are welcome for vulnerabilities in the files published by this repository. Installation,
documentation, and compatibility problems that are not security vulnerabilities belong in GitHub Issues.
