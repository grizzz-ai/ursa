# Support

Use [GitHub Issues](https://github.com/grizzz-ai/ursa/issues) for reproducible bugs,
installation failures, documentation errors, and compatibility reports.

After the public launch enables it, use
[GitHub Discussions](https://github.com/grizzz-ai/ursa/discussions) for questions,
usage ideas, and general feedback. Do not include credentials, tokens, private keys, or private repository
content in either channel.

For a suspected security vulnerability, follow [the security policy](SECURITY.md).
